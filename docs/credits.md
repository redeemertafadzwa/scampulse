# Credits & acknowledgements

Everything used is listed here, as required by the challenge.

## Libraries (Stage 1)
- **scikit-learn** 1.7.2 — TF-IDF + logistic regression (BSD licence).
- **pandas** 2.3.3 — dataset handling (BSD).
- **NumPy** 2.3.5 — numerics (BSD).
- **joblib** 1.5.2 — model persistence (BSD).

All actively maintained; versions pinned in `requirements.txt`.

## Web app (Stages 2-6)
- **Django** 6.1.1, **Django REST Framework** 3.18.1, **WhiteNoise** 6.12,
  **gunicorn** 23, **python-dotenv** 1.1 (all actively maintained, pinned).
- **Fonts:** Bricolage Grotesque + Source Sans 3 (SIL OFL). Currently loaded via
  Google Fonts with a system-font fallback; **self-hosting the woff2 files is the
  one remaining polish item** (see known-limitations).
- **Icons:** all original — bottom-nav icons are hand-written inline SVG; the app
  icon (icon-192/512.png) is generated by `scripts`/Pillow. No external icon set
  was needed. (Phosphor/Lucide remain the fallback if more icons are added.)
- **Photos:** none used yet; if added, only Unsplash / Pexels.
- On-device model runs in a hand-written JS inference function (no ML library in
  the browser); the model.json is produced by scikit-learn on the server.

## Data
- `Cyber_Shield_Training_Dataset.csv` — challenge-provided (12 unique messages;
  used only as a reference, not for measuring accuracy).
- All other data is **synthetic**, generated by `ml/make_datasets.py`. Every link
  uses `example.invalid`. No real personal data is included.
